Como jogar

Perguntas frequentes

Posso usar o site para conferir resultados?

Sim. Os resultados vêm da API pública da Caixa quando disponível, com backup local. Sempre confira no site oficial antes de qualquer decisão.

Como criar confiança com os visitantes?

Informações claras sobre regras, aviso de que não vendemos bilhetes e links para a Caixa. Dados atualizados e conferência transparente.

O site funciona offline?

Com o PWA instalado, páginas e dados já visitados podem ser consultados offline. Novos resultados exigem conexão.

Como compartilhar minha aposta?

Use "Compartilhar link" no simulador. O link inclui jogo e números para quem abrir carregar a mesma combinação.

Privacidade

Seleções e favoritos ficam apenas no seu navegador (localStorage). Não coletamos dados pessoais nem enviamos apostas a servidores próprios. Ao usar a API da Caixa, aplicam-se as políticas do site oficial.

Aviso legal: Bom de Sorte é um projeto informativo e educacional. Não realiza vendas de bilhetes nem garante prêmios. Jogue com responsabilidade (+18). Resultados oficiais: Caixa Econômica Federal.
