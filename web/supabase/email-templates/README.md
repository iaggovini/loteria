# Templates de e-mail (Supabase Auth)

Cole cada arquivo em **Supabase → Authentication → Emails → Templates**, na aba correspondente, e use o assunto indicado.

| Aba no Supabase | Assunto | Arquivo |
|---|---|---|
| Confirm signup | Confirme seu cadastro no Bom de Sorte | `confirmar-cadastro.html` |
| Reset password | Redefinição de senha — Bom de Sorte | `redefinir-senha.html` |
| Change email address | Confirme seu novo e-mail — Bom de Sorte | `alterar-email.html` |

Os estilos ficam inline porque a maioria dos clientes de e-mail (Gmail, Outlook) ignora `<style>` e CSS externo.
